# Checkpoint #4 - Monitorando eventos da aplicação
  
Monitorar eventos gerados pela aplicação e nos tópicos de mensagens, usando serviços de observabilidade do Google Cloud

## Provedor Utilizado  
* Google Cloud Monitoring  
* Google Cloud Logging  

  
## Como rodar localmente  
  
Os comandos serão encaminhados no Canvas, junto com a atividade.
   
  
## Pré requisitos  

  Sem pré requisitos   
    
### Passo a passo  
  
1. Clone o repositório para sua máquina:  
   `git clone https://github.com/angmaximo/pucminas-checkpoint4.git`  
  
2. Entre na pasta do projeto   
   `cd pucminas-checkpoint4`
